# Novel View Synthesis challenge rules

📅 **Submission deadline:** April 25, 2027, 23:59 Anywhere on Earth (AoE; UTC−12).

Synthesize the target views from the supplied camera observations. Render each target image at **2048 × 1080**. The ranking metric is peak signal-to-noise ratio (PSNR), following the previous SoccerNet NVS edition.

Use only the images and scene information allowed by the dataset's access terms. Challenge target images are withheld for evaluation. The [evaluation guide](evaluation/README.md) describes image matching and the metric implementation.
