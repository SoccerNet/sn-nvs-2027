# NVS Challenge Rules — draft

📅 **Submission deadline:** April 25, 2027, 23:59 Anywhere on Earth (AoE; UTC−12).

Participants will render the supplied target views from the 2027 simulator scenes. The ranking metric is **PSNR at 2048 × 1080**, following the 2026 NVS challenge. SSIM and LPIPS were reported in 2026; their 2027 role is still to be confirmed. The prior `scene-*-challenge/renders/*.png` submission layout is a reference until the new scene and camera IDs are frozen.

Challenge target images are organizer-only ground truth. Participants must respect the dataset access terms. Allowed external data, per-scene training, compute budget, image color handling, missing-render policy, exact cross-scene aggregation, submission limits, tie policy, and appeal procedure remain to be set. See [evaluation](evaluation/README.md) for the local metric code. These rules become official only when the task launches.
